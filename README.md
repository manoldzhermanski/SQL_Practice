# SQL Practice

A collection of SQL problems and exercises solved as part of my preparation for a career in **Data Engineering and Data Science**.

The repository focuses on building practical SQL skills through problem solving, with particular emphasis on areas that require further practice and deeper understanding.

## Repository Structure

### [Employees Dataset](./Employees_Dataset/)

A collection of SQL exercises based on the **MySQL Employees** sample database.

The exercises cover a range of SQL concepts, including:

* Filtering and sorting
* Aggregations and `GROUP BY`
* `JOIN`s
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Date and time operations
* `NULL` handling
* Complex query logic

The problem descriptions are created with the help of **ChatGPT** and are specifically focused on areas where I need additional practice.

More information about the dataset, its structure, and the exercises can be found in the [Employees Dataset README](./Employees_Dataset/README.md).

## Goals

* Strengthen SQL fundamentals
* Improve problem-solving skills
* Practice writing clear and efficient queries
* Prepare for SQL-focused technical interviews
* Build a solid foundation for further work in Data Engineering and Data Science
